# Code of Conduct

This code applies to contributions, issue discussions, reviews, and other project spaces or interactions.

## Expected behavior

Contributors and maintainers are expected to be respectful, constructive, and inclusive.

## Unacceptable behavior

Harassment, discrimination, threats, doxxing, and personal attacks are not acceptable.

## Reporting a concern

Report conduct concerns privately to **keelmatrix@gmail.com** with the repository, relevant links or dates, and only
the supporting context needed to investigate. Do not include credentials, request data, customer data, or scripted
scenarios that contain sensitive values. Vulnerability reports must follow [`SECURITY.md`](SECURITY.md).
